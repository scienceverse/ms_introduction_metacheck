# papercheck_paper

Paper introducing the Papercheck tool, illustrated based on Psychological Science papers

Set up [apaquarto](https://wjschne.github.io/apaquarto/):

``` r
quarto::quarto_add_extension("wjschne/apaquarto", no_prompt = TRUE)
```

## Data and Code

The /data folder contains .rds and Rdata files. These files are generated by code, but often require:
- internet access
- access to an LLM
- hours to run

We therefore run these files once, and store the results. It is possible that these datafiles are not completely reproducible when the online resources that were used to create them change. 
For example:
- authors can close projects on the OSF, making them inaccessible
- authors can open projects, making them accessible
- OpenAlex might update their database with new information
