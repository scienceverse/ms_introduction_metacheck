# Description
This repository accompanies the paper introducing **Metacheck**, a modular tool for assessing the presence (or absence) of best research practices in scientific manuscripts. As a demonstration, we apply **Metacheck** to a sample of articles published in Psychological Science.
All analyses, including data processing, analyses, and figure generation, are documented in `manuscript.qmd`.

To render only the manuscript, run:

```bash
quarto render manuscript.qmd
```

# Data

The files in the `/data` folder contain `.rds` and `RData` files generated by running code, but often require:

- internet access
- access to an LLM
- hours to run


To make the analyses easier to reproduce, we ran the data modules once and stored the resulting files in the `data/` folder. However, these files may not be fully reproducible if the online resources used to create them change over time. For example:

- Authors can close projects on the OSF, making them inaccessible
- Authors can open projects, making them accessible
- OpenAlex might update their database with new information
